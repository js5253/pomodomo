# pomodomo

A physical timer that runs on the ESP32 - can be a pomodoro as well a normal countdown/stopwatch. It is modeled after the [ones on Amazon](https://www.amazon.com/Rotating-Pomodoro-Minutes-Productivity-Vibration/dp/B0D7JG4VLD).

https://josesanchez.dev/blog/adventures-in-embedded-systems-land/
